# 🎓 ALTS University Management System

## 📌 Project Overview

The **ALTS University Management System** is a web-based application designed to simplify and organize university activities through a centralized portal.

The system provides different dashboards and functionalities for administrators, faculty members, students, accountants, and librarians.

It helps manage student information, faculty details, courses, attendance, examinations, results, notifications, and other academic activities.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **Tailwind CSS** – Styling and responsive design
- **JavaScript** – Application functionality
- **React.js** – Component-based user interface
- **Font Awesome** – Icons
- **Visual Studio Code** – Development environment

## ✨ Key Features

### 1. User Authentication
- Login interface
- Role-based access
- Separate dashboards for different users

### 2. Student Management
- Add student details
- Update student information
- Delete student records
- Search student information

### 3. Faculty Management
- Manage faculty details
- View faculty information
- Assign courses to faculty

### 4. Course Management
- View available courses
- Manage course materials
- Access course information

### 5. Attendance Management
- View student attendance
- Track attendance percentages
- Access attendance information

### 6. Examination and Results
- Manage examination information
- View examination schedules
- Access student results
- Manage hall ticket information

### 7. Financial Management
- View financial records
- Track fee payment information

### 8. Notifications
- View university announcements
- Create notifications
- Schedule notifications

### 9. Additional Modules
- Enrollment Management
- Department Information
- Disciplinary Management
- Scholarship and Offers
- Infrastructure Issue Reporting
- Student and Faculty Profiles

## 👥 User Roles

## ⚙️ How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the main HTML file.
4. Ensure you have an internet connection because the project loads React, Tailwind CSS, Babel, and Font Awesome from CDNs.
5. Run the application using Live Server.
6. Explore the available modules.
